## 🚀 Como entregar este projeto na plataforma da DIO

1. **Crie um repositório no GitHub:**
   - Acesse seu GitHub e clique em **New** (Novo Repositório).
   - Dê um nome descritivo (ex: `miniguia-estudos-notebooklm-santander`).
   - Defina como **Público** e marque a opção de adicionar um arquivo **README.md**.
2. **Edite o arquivo README.md:**
   - Copie o conteúdo deste template.
   - Substitua as partes entre colchetes `[...]` com as informações e aprendizados do seu caderno no NotebookLM.
   - Salve e faça o commit das alterações no seu GitHub.
3. **Envie na DIO:**
   - Copie a URL do seu repositório no GitHub (ex: `https://github.com/seu-usuario/nome-do-repositorio`).
   - Cole o link na página de entrega do desafio na plataforma da DIO e clique em **Entregar**.
